# Gift Studio – Billing Program

A command-line billing program for a gift shop, written in core Python.

## What it does
- Shows a product menu with prices
- Takes product numbers and quantities from the user
- Adds up repeated products and prints a formatted bill

## Concepts used
Dictionaries, lists, loops, conditions, input validation, f-strings

## How to run
python gift_studio_billing.py
